# NITTC Scheduler-fork

学校を問わず使える時間割・課題・予定管理アプリです。Androidで動作します。

A授業日・B授業日や日程変更を考慮し、その日に必要な時間割を確認できます。授業ごとの課題や予定、通知もまとめて管理できます。

## 本家との違い

このリポジトリは、NITTC Schedulerをベースに、複数端末での利用と通知まわりを中心に機能を拡張したフォークです。

主な違いは次のとおりです。

- MEGAを使ったクラウド同期に対応
- 同期ボタンを押すとすぐ同期、長押しすると同期設定を表示
- ローカルとMEGA側で更新が競合した場合は、更新時刻を比較して新しい方を優先
- MEGA同期が失敗した場合は自動で再試行
- アプリ起動時や通知処理時にもMEGA同期を試行
- Nearbyなど近くの端末との同期案内を抑制する設定を追加
- 課題・予定の通知経路を見直し、AlarmManager・Receiver・WorkManagerの状態を追跡しやすく改善
- 設定画面から即時通知やアラーム経由の通知テストが可能
- 授業開始前・終了前の通知設定や通知内容のカスタマイズを強化

本家の時間割、課題・予定、カレンダー連携、ウィジェット、ローカルAIなどの基本機能はそのまま利用できます。

## このフォークの独自機能

### MEGA同期

MEGAアカウントを使って、時間割、課題、予定、通知設定などを複数端末間で同期できます。MEGAアプリを別途起動する必要はありません。

通常は同期ボタンを押すだけで同期できます。設定を変更したい場合は同期ボタンを長押しします。

### 通知の安定性向上

課題・予定の通知について、アラーム登録から通知表示までの経路を見直しています。Android側で正確なアラームが利用できない場合も、通知そのものが失われにくいようフォールバックを行います。

設定画面には通知テスト機能があり、通常の通知とAlarmManager経由の通知をそれぞれ確認できます。

### 近くの端末との同期を抑制

MEGA同期をメインで使う場合、近くの端末との同期を促すダイアログを表示しないようにできます。既存の端末間同期機能自体は残しているため、必要なときだけ使えます。

## 主な機能

- 時間割管理
  - 教科名、担当教員、教室などを登録
  - A/B授業日に対応
  - 授業変更、休講、長期休暇、試験日程に対応
  - 時限数や授業時間を変更可能
- 課題・予定管理
  - 時間割と関連付けて登録
  - 期限、完了状態、リマインダーを管理
- 通知
  - 課題・予定のリマインダー
  - 授業開始前や授業終了前の通知
  - 通知時刻や内容をカスタマイズ可能
- カレンダー連携
  - 授業や課題・予定を端末のカレンダーへ反映
- ウィジェット
  - 今日や今後の授業をホーム画面から確認
- MEGA同期
  - 複数端末間で時間割、課題、予定、各種設定を同期
  - アプリ起動時や通知処理時にも同期を試行
  - 同期失敗時は自動的に再試行
- 近くの端末との同期
  - 必要な場合は従来の端末間同期も利用可能
  - MEGA同期を使用する場合は、端末間同期の案内ダイアログを無効にできます
- ローカルAIによる時間割読み取り
  - 対応モデルを使い、画像から時間割を取り込めます

## MEGA同期

設定画面からMEGAアカウントへログインすると、アプリのデータをMEGA経由で同期できます。MEGAアプリやAndroidのファイルピッカーは不要です。

MEGAのパスワードや2段階認証コードそのものは保存しません。ログイン後はセッション情報を利用して同期します。

同期ボタンを押すと同期を実行し、長押しすると同期設定を開けます。

ローカルとMEGA側の両方に変更がある場合は、更新時刻を比較して新しいデータを優先します。

MEGA同期では、主に次のデータが同期されます。

- 時間割、A/B日、授業変更、休講、長期休暇
- 試験日程・試験時間割
- 課題・予定とリマインダー設定
- 授業通知設定
- アプリ内の各種設定

Androidの通知権限、正確なアラーム権限、現在表示中の通知、端末カレンダー上に作成済みのイベント、WorkManagerやAlarmManagerの実行状態など、端末固有の状態は同期されません。

## 通知について

課題・予定の期限や授業時刻に合わせて通知できます。

Androidのバージョンによっては、通知権限や「正確なアラーム」に関する許可が必要です。通知が届かない場合は、アプリ内の通知設定に加えてAndroid側の権限設定も確認してください。

設定画面には通知テスト機能があり、即時通知やAlarmManager経由の通知経路を確認できます。

## ローカルAIについて

画像から時間割を読み取るために、対応するローカルAIモデルを利用できます。

ローカルAIは端末上で動作するため、CPU・RAMを多く使用します。目安として、RAM 8GB以上の比較的新しいAndroid端末を推奨します。より大きなモデルを使う場合は、RAM 12GB以上の端末の方が安定します。

モデルによっては、ダウンロード時にHugging FaceのRead権限アクセストークンが必要です。

## 動作確認済みの機種

- Nothing Phone (2)
- Nothing Phone (3)

端末やAndroidバージョンによって、通知、バックグラウンド処理、カレンダー連携などの挙動が異なる場合があります。
